## 概要

[NamaMeto](/Store/NamaMeto/NamaMetoStore.html)（メトロノーム）、[NamaChu](/Store/NamaChu/NamaChuStore.html)（チューナー）、[NamaHam](/Store/NamaHam/NamaHamStore.html)（ハーモニー）の3つを1つにまとめた統合アプリ。
このNamaSound+自体は外側の入れ物だけで、中身は各アプリがそのまま開かれます。

### 使い方
上部のタブを押すと3アプリを切り替え。
左上の「設定」から言語やスリープ防止を設定すると3アプリまとめて変更できます。各アプリ内で個別に変更もできます。

### 設定
タブ切替時に音を止める設定、表示サイズの調整、強制リロード、PWAとしてインストール、各アプリを直接開くURLのコピー。

### 画面説明（スクリーンショットの見方）
1) メトロノームタブ: NamaMeto
2) チューナータブ: NamaChu
3) ハーモニータブ: NamaHam
4) 共通設定: 左上の歯車から開く、統合側の設定。
